# WCNS 0.1 发布候选已知限制

这些限制是当前实现边界，不应通过静默降阶、占位零值或忽略配置来规避。

## 物理与数值模型

- 仅支持单组分、热完全理想气体和常数比热比；没有多组分、化学反应、真实气体、湍流或
  转捩模型。
- 时间推进仅为显式 SSPRK3；没有隐式定常推进、本地时间步、多重网格或双时间步。
- 低 Mach 预处理尚未实现。配置 schema 不接受预处理开关，所有无粘通量直接使用
  Rusanov、HLLC 或 Roe。
- 黏性计算目前从程序内 `TransportConfig` 使用默认 `Pr=0.72` 和常黏度；底层已有
  Sutherland 模型，但严格运行配置尚未暴露输运模型选择和参数。
- 源项仅包括均匀守恒源、体力和当前制造源；没有通用表达式解释器或运行时动态源项插件。
- 当前发布矩阵验证了空间算子和 SSPRK3 推进，但尚未给出完整制造解的黏性空间阶、独立的
  时间收敛阶或稳定 CFL 上界。配置中的默认 CFL 不是对任意网格/状态的稳定性保证。

## 网格、边界与并行

- 只读取二维/三维结构 CGNS zone、顶点坐标、顶点定位的 `PointRange` 物理边界和共形
  `GridConnectivity1to1`；不支持非结构、混合、重叠、滑移接口、AMR 或运动网格。
- 随附 CGNS 以 ADF 后端构建，不能读取仅有 HDF5 后端才能打开的 CGNS 文件。
- 物理边界 ghost 只保证由边界条件构造的原始量及相应守恒量有效。边/角 ghost 不填充，
  ghost 坐标、度量、梯度和其他派生量均不得读取。
- 自动分区是确定性的递归二分，不是图划分器；它以单元数负载为目标，尚不计连接通信量、
  边界类型或异构硬件代价。过窄块会按 profile 模板下限明确拒绝。
- halo 通信使用 MPI，但当前计算/通信没有系统性重叠。CGNS 读写和原 zone 输出重组也不是
  并行 I/O；大规模网格的启动、检查点和输出扩展性尚未验证。

## 输入、输出与扩展

- 配置 schema 固定为版本 1，采用平面 `key=value` 文本；没有 YAML/JSON、单位系统或表达式。
- CGNS/Tecplot 只输出 cell-center 场。涡量、散度、Q 判据、壁面剪切和壁面热流尚未成为
  内建字段；请求未知量会失败，不会输出占位值。
- 自定义字段和统计量需要在 C++ 启动装配处注册并重新编译；标准程序不加载动态插件。
- 检查点是 WCNS 内部 CGNS 布局，只承诺相同网格与数值签名下跨合法 rank/叶块划分恢复，
  不承诺与其他 CFD 软件互换。
- 当前二进制没有稳定的 WCNS 库 ABI/API 承诺；安装目标面向运行程序和验证工具。由于上游
  CGNS 4.4.0 自带的 CMake install 规则，安装树还会包含 CGNS 静态库、头文件和命令行工具；
  这些文件保持 CGNS 自身的接口和许可证，不代表 WCNS 提供链接兼容性承诺。

## 发布与平台

- 已实测环境为 Windows 10、CMake 3.28、MinGW-w64 GCC 8.1、Python 3.14 和 Intel MPI
  2021.10。其他 Windows/Linux 编译器及 MPI 实现尚未进入发布矩阵。
- MinGW 构建的程序运行时需要相容的 `libgcc_s_sjlj-1.dll` 和 `libstdc++-6.dll`；MPI 版本
  还需要 Intel MPI 的 `impi.dll` 及运行环境。`cmake --install` 不复制这些工具链运行库。
- WCNS 自有代码尚未选择对外许可证，因此当前候选不应作为可自由再分发的开源发行版；见
  [`LICENSE.md`](../LICENSE.md)。
