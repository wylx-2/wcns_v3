# 阶段 I 设计：两套静态几何 profile

状态：已获项目负责人批准，允许在 `stage/i-geometry-profiles` 分支实施。

## 1. 目标与边界

阶段 I 实现 `phenglei_wcns` 与 `scmm6_wcns` 两套不可拆分的静态几何 profile，输出统一语义的真实单元中心坐标、物理 Jacobian 和真实面有向面积矢量，并建立几何初始化所需的分阶段连接计划、共享面唯一所有者和守恒积分权重。

本阶段只进行网格、度量、通信计划和守恒权重验收；不改变阶段 E 的 Euler residual，不实现阶段 J 的高阶面通量、Riemann 接入、`FaceFluxHalo` 或实际源项。

## 2. I1：profile 工厂和绑定

- 新增 `AlgorithmProfileKind`、profile 专属 `MetricMethod`、插值、差分和边界闭合标识。
- 所有部件只能由 `ProfileFactory` 成套创建并携带同一 profile 标识。
- 配置字符串、日志和重启签名固定为 `phenglei_wcns` 或 `scmm6_wcns`。
- 混合 profile 部件、未知配置和重启不一致确定性失败。

## 3. I2：公共冻结输出与参考诊断

- `MetricField` 只保存真实 `CellCoordinates`、真实单元 `J` 和真实 I/J/K 面的面积矢量；构造结束后只读。
- `GeometryDiagnostics` 独立保存有限体积 `reference_volume/reference_area` 和高阶/参考相对差，不允许覆盖高阶 `J`。
- 面积和单位法向只由面积矢量派生；`NumericalFloors` 对 `J` 和面积进行集中校验。
- 现有有限体积 `compute_metrics` 保持兼容，作为参考几何生成器而非高阶回退的别名。

## 4. I3：`phenglei_wcns` 度量

- 从 CGNS 顶点构造每个活动方向 `2*Nv-1` 的加密交错临时工作区。
- 坐标、嵌套乘积和 Jacobian 全部使用同一 `GridDelta`。
- 二维使用退化二维公式；三维使用文档第 3.3 节的九个对称守恒式。
- 只抽取奇偶位置对应的真实中心、真实面和真实单元 `J`，物理边界外不创建几何字段。
- 默认 `metric_fallback=strict`；仅显式 PH 对照配置允许记录后使用有限体积参考值。

## 5. I4：`scmm6_wcns` 度量

- 用张量积 `I6^{v->c}` 生成真实中心坐标，每个活动方向至少六个顶点。
- 共同中心导数严格使用同一 `delta=D6*I6` 对坐标、乘积、面积矢量散度和 Jacobian 求导。
- 中心面积矢量只沿自身法向用同一 `I6` 插值到真实面。
- 物理边界使用冻结的单边插值/差分，不读取任何物理 ghost 几何。

## 6. I5：连接计划和唯一共享面

- `GeometryHaloPlan` 明确区分 `GeometryVertex`、带阶段号的 `GeometryOperand` 和 `SharedMetric`，记录 profile、层宽、连接、轴置换、方向和所有者。
- PH 的顶点/操作数层宽为 2/3；SCMM6 为 2/5，最终中心量到面为 3。
- 同进程和 MPI 使用相同描述符；消息键包含种类、阶段和连接号。
- 共享面所有者按较小全局块号、再按连接号确定；发布后两侧面积、坐标和外法向关系必须通过验证。
- 普通连接完成轴置换/反向；周期描述携带正交 `Q` 和平移 `d`，非法旋转确定性失败。
- 跨多个连接的临时几何操作数只接受唯一 donor 路径；缺失、分支或不一致路径失败。

## 7. I6：守恒权重和冻结

- profile 专属一维导数矩阵生成正积分权重，并验证 `D^T w=e_R-e_L`、唯一性、残差和正性。
- 单块逻辑矩形使用张量积单元权重；周期方向使用循环算子和单位权重。
- 多块组装唯一共享连接面和物理边界面自由度，验证加权内部/连接面抵消及物理边界系数。
- 初始化完成后冻结 `MetricField` 和 `GlobalConservationWeights`，释放临时几何工作区。

## 8. 测试注释约定

所有 `tests/*.cpp` 中作为验收入口的 `test_*` 函数，以及单独测试可执行文件中的主要 `test_*` 子函数，都在函数定义前添加一条简短 C++ 注释，说明其对应的测试目的。注释只说明验收意图，不复述实现步骤。

阶段 I 新增测试至少分为：profile 绑定、线性算子、PH 度量、SCMM6 度量、连接计划/共享面、周期变换、守恒权重和非法几何路径。每个函数按上述约定注释。

## 10. 正式验收标准

- 两套 profile 的部件交叉组合全部失败。
- 恒等映射逐点得到 `J=1` 和笛卡尔面积矢量；一般仿射映射达到舍入误差。
- 光滑扭曲网格的几何误差随加密按各 profile 声明规律下降，离散度量恒等式满足规定容差。
- 将物理 ghost 几何保持为 NaN/不可访问后全部测试通过。
- 单块与多块切分的共享面坐标、面积和外法向关系一致；轴置换、反向及旋转周期变换通过。
- PH `N=4..12`、SCMM6 `N=5..12` 的一维权重严格为正，守恒恒等式残差接近舍入误差；多块共享面加权贡献抵消。
- 阶段 G 规格检查、串行 Release 全部测试、MPI Release 全部测试通过；阶段 E 代表结果不变。

## 11. 明确不在阶段 I 范围内

- 无粘/粘性高阶面通量和 `FaceFluxHalo`；
- 物理状态 ghost 的温度型迁移和三个边界算子；
- 实际源项求值；
- 动网格、非共形连接、overset 或 AMR；
- 为通过测试而跨 profile 复用离散部件或静默有限体积回退。
