# 阶段 K 设计：粘性 WCNS

状态：项目负责人于 2026-09-02 批准开始阶段 K；K0--K6 已在 `stage/k-viscous-wcns` 分支完成，正在执行 K7 正式验收。阶段 J 的无粘求解路径继续作为独立回归基线，阶段 L 不得提前进入。

## 1. 范围与非目标

阶段 K 实现层流 Navier--Stokes 粘性空间算子及显式时间步限制，严格采用《算法补充.md》第 6 节的无量纲约定。范围包括真实单元 primitive 梯度、连接梯度通信、真实面粘性迹与通量、粘性面通量通信、常黏度/Sutherland 输运、壁面强约束、`1/Re` 单次缩放和 SSPRK3 集成。

本阶段不实现湍流、混合气体、非 Fourier 热传导、非 Stokes 本构、移动网格、HLLC、特征重构、生产算例配置或 CGNS 流场输出。后五项分别保留给阶段 L/M；阶段 K 的 Couette、导热和制造解验收使用确定性测试夹具。

## 2. K0：配置、字段和版本语义

- `TransportConfig` 只能选择 `constant | sutherland`，并保存严格正的 `Pr`。常黏度保存 `mu_const/mu_ref`；Sutherland 保存 `mu(T_ref)/mu_ref` 和 `S*/T_ref`，二者不得交叉使用。
- `GradientOperandFaceField` 临时保存 `(u,v,w,T)\otimes(S_x,S_y,S_z)`，只拥有真实面和连接法向 halo：PH 层 0--1、SCMM6 层 0--2。状态 halo 不含邻块面度量，禁止接收块据此重复构造邻块 `q*S`。
- `PrimitiveGradientField` 只以真实单元为权威域，保存 `(u,v,w,T)` 对 Cartesian `(x,y,z)` 的 12 个梯度分量。连接 halo 对 PH 为 2 层、对 SCMM6 为 3 层；物理边界方向及边角存储保持 NaN/非法。
- `ViscousFaceFluxField` 只拥有真实面及 profile 散度所需的连接法向 halo：PH 层 0--1，SCMM6 层 0--2。它与无粘面通量使用不同消息种类、tag 空间和版本。
- 梯度版本和粘性通量版本绑定当前 RK 子步及 profile。不同 profile、不同版本、缺层或非有限值在消费前确定性失败。
- 二维仍保存三分量速度，但要求 `w=0`，所有 `z` 导数、含 z 的剪切应力和 z 动量粘性通量严格为零。

## 3. K1：守恒型 primitive 梯度

1. 读取阶段 J 同一事务生成的温度型 primitive 真值，不建立第二套粘性 ghost。
2. 在每个真实面按 profile 中心插值 `(u,v,w,T)`；内部及连接面使用状态 halo，物理边界只读取该面法向 ghost slab，不读取边/角 ghost。
3. 形成本块拥有的 `q*S_x`、`q*S_y`、`q*S_z`，由唯一共享面所有者发布并同步 `GradientOperandFaceHalo`，再用 profile 对应的通量导数得到真实单元 Cartesian 梯度并除以一次正 Jacobian。
4. 连接附近采用与单块内部相同的中心导数；物理边界采用 PH `D2` 或 SCMM6 单边 `D4`。临时面值只使用真实面和连接面 halo，不存在物理 ghost 几何。
5. 仿射网格上的常量及线性 `(u,v,w,T)` 必须达到舍入误差；将所有非状态物理 ghost 填为 NaN 后结果不变。

## 4. K2：`GradientHalo` 与面插值

- `GradientOperandFaceHaloPlan` 使用 PH 层 0--1 或 SCMM6 层 0--2；普通连接施加面方向，旋转周期对速度三行执行二阶张量变换、对温度行执行矢量变换。该临时对象与粘性面通量具有不同消息 kind 和版本。
- `GradientHaloPlan` 从权威连接描述生成 PH 2 层或 SCMM6 3 层 cell 对；同 rank 和 MPI 使用同一计划。
- 普通连接只映射索引。旋转周期对标量温度梯度执行 `Q^T grad(T)_donor`，对速度梯度执行 `Q^T grad(u)_donor Q`，得到接收侧 Cartesian 张量。
- 内部及连接面梯度用 PH `I4` 或 SCMM6 `I6` 中心插值；物理边界没有梯度 ghost，使用同 profile 的真实单元单边插值。
- 每个交换消息检查 kind、profile、版本、连接、层数、长度和有限性；二维旋转不得产生 z 分量。

## 5. K3：输运、应力和热流

- 常黏度返回配置的 `mu_const/mu_ref`。Sutherland 返回
  `mu(T_ref)/mu_ref * T^(3/2) * (1+S)/(T+S)`，并验证 `T>0`。
- 只在真实面插值温度后求 `mu(T_f)`；不平均两侧黏度，也不创建 ghost 输运系数。
- `chi=mu/((gamma-1)*Ma^2*Pr)`，Stokes 应力和 Fourier 能量项严格按《算法补充.md》第 6.2 节组装。
- `ViscousFluxKernel` 返回每单位物理面积的 Cartesian 粘性通量；调用方只用一次真实面矢量变换成计算空间通量。
- 常量梯度的应力、热流及能量通量与解析值达到舍入误差；`T=1` 时 Sutherland 恢复配置参考比值。

## 6. K4：`ViscousBoundaryTrace`

- 非固壁保留原始面值和原始梯度。滑移/对称面不在阶段 K 中擅自增加无滑移条件。
- 无滑移壁始终把真实面速度强制为 patch 的 `wall_velocity`，不受无粘 `strong_boundary_face_state` 开关控制。
- Dirichlet 法向导数由壁面值和内侧真实单元中心构造：PH 对 0--4 次、SCMM6 对 0--6 次多项式精确；只读取真实中心坐标/状态和真实边界面几何。
- 绝热壁强制 `grad(T) dot n=0` 并保留原始切向温度梯度；等温壁强制 `T=T_wall` 并使用上述 Dirichlet 法向导数。常量 patch 壁速度和壁温的切向导数为零。
- 壁面压力取当前 profile 的内部压力迹，密度由同一状态方程闭合；全部结果通过统一 `NumericalFloors`。

## 7. K5：粘性通量散度与求解器集成

- 粘性面通量由本块真实面计算，共享连接面使用阶段 I/J 相同的确定性所有者；随后同步 PH 层 0--1或 SCMM6 层 0--2。
- 粘性散度使用与当前 profile 相同的导数；只在装配到 `Residual=dU/dt` 时乘一次 `1/(Re*J)`，应力、`chi`、面通量和源项均不得再含 `1/Re`。
- 新的粘性 WCNS 求解驱动在每个 RK 子步严格执行：公共状态更新/通信/物理 ghost、无粘通量、真实单元梯度、梯度通信、粘性通量、粘性通量通信、两类散度、源项。
- 阶段 J 的 `InviscidWcnsSolver` 保持独立且结果不变；关闭粘性路径不得创建梯度/粘性通量对象。
- 局部显式时间步采用算法文档给定的无粘加粘性分母。配置分别保存 `Cv_phenglei_2d_ssprk3`、`Cv_phenglei_3d_ssprk3`、`Cv_scmm6_2d_ssprk3`、`Cv_scmm6_3d_ssprk3`，当前冻结默认值均为 4.0 且必须严格为正；求解器只能选择与当前 `(profile,dimension,SSPRK3)` 相符的一项，MPI 取全局最小值。该默认值是阶段 K 的保守起步值，后续生产算例仍须按网格和物性验证 CFL 裕量。

## 9. 正式验收卡口

- 两套 profile 的仿射线性场梯度、常量应力和热流达到规定舍入误差；Dirichlet 壁面导数满足冻结的多项式矩。
- Couette 流和线性导热的面迹、通量及稳态残差正确；至少一个粘性制造解随网格加密达到预先声明的误差下降门槛。
- 绝热壁法向热流为零；等温壁温和无滑移壁速度在每个真实边界面满足强约束。
- 将 `Re` 改为两倍时，在相同状态下粘性残差严格减半；Sutherland 在 `T=1` 恢复参考黏度比。
- 物理边界 ghost 的公共版本同时影响无粘重构和粘性梯度；边角状态以及 ghost 坐标、度量、梯度、输运和通量保持 NaN/未分配且不被读取。
- PH 2 层、SCMM6 3 层梯度 halo，以及两套 profile 的粘性面通量层、方向、旋转、owner 和版本均通过同 rank/MPI 测试。
- 单块、串行多块和双 rank 的粘性残差及一个 SSPRK3 步满足规定容差；阶段 H--J 全部回归继续通过。
- 阶段 G 规格检查、串行/MPI Release、`git diff --check` 和工作树检查全部通过，然后等待项目负责人人工验收。

### 9.1 冻结的数值门槛

- 双块自由流在串行和双 rank 下的全局残差及一次 SSPRK3 状态误差均小于 `8e-11`。
- Couette 夹具取物理高度 `H=8`、`u=y/H`、常温常压；质量和三个动量残差小于 `2e-10`，能量残差与 `(du/dy)^2/Re` 的误差小于 `2e-10`。
- 线性导热夹具取 `T=1+y/H`、`rho=1/T` 以维持常压；只把粘性热传导的能量平衡作为本项判据，其能量残差小于 `2e-10`。Rusanov 对变密度静止接触面的无粘耗散不属于导热误差，不用其他方程残差冒充导热验收。
- 正弦温度制造解在单位正方形内部域比较 `24^2 -> 48^2` 网格的能量粘性残差 L2 误差；PH 的误差下降倍数必须大于 12，SCMM6 必须大于 40。门槛在正式验收前冻结，不得因结果失败静默放宽。
- 二维和三维仿射线性梯度容差分别为 `2e-13` 和 `2e-12`；壁面、应力、热流、Re 缩放及旋转变换沿用相应测试中冻结的舍入误差容差。
