# 阶段 O 设计：生产算例系统验收与发布候选

状态：O0 冻结规格；完成后只在有算法证据时单独提交阈值修订。

阶段 O 不再增加第二条“测试求解器”路径。所有发布算例必须由确定性 CGNS 生成器产生网格，
由 `wcns_run --config` 读取严格 schema，并由独立重读/解析工具验收。阶段 K/L 暂缓的人工检查
与阶段 M/N 的机制验收在 O6 发布候选处集中接受项目负责人人工检查。

## 1. O0 必修生产接口

正式算例开始前补齐两项不能由测试夹具替代的生产能力：

1. `CgnsReader` 读取 `GridConnectivity1to1_t/Periodic_t` 的旋转中心、旋转角和平移，转换为
   `PeriodicTransform` 并验证连接面顶点坐标。无 `Periodic_t` 的普通连接保持恒等变换；非法
   旋转、非互逆周期连接或坐标不匹配在分配流场前失败。
2. 配置允许按 CGNS 边界名提供 `wall_velocity_x/y/z`、`wall_temperature` 和可选入口/远场
   `rho,u,v,w,temperature|pressure`。边界数据进入配置摘要和数值重启签名；切分后的同名边界
   继承同一数据。未提供时保留阶段 N 的初场默认规则。

同时补充 `linear_conduction` 和带解析温度参数的 `couette` 初场，使解析黏性状态可由正式配置
生成。所有物理边界 ghost 仍只填物理量，算例/输出不得读取其坐标、度量或派生量。

## 2. 资产布局与复现入口

- `cases/config/`：可版本管理的 schema v1 配置模板；
- `tools/generate_release_cgns.cpp`：由尺寸参数确定性生成二维/三维、单区/多区/周期网格；
- `tools/run_release_matrix.py`：只负责生成配置、调用正式程序、检查退出码和汇总 manifest；
- `tools/validate_release_case.cpp`：独立 CGNS/TXT 重读，计算误差、守恒、正性和串并行差；
- `cases/baselines/`：冻结的阈值/小型数值基线及生成提交，不保存无法追溯的截图；
- `docs/stage-o-acceptance.md`：最终环境、命令、配置摘要、数值和性能结果。

快速矩阵使用小网格进入 CTest；发布矩阵使用本文件给出的中等网格从 Release 构建单独执行。
二者使用同一生成器、配置模板、求解入口和验证器。测试不得从构建目录中的旧输出推断通过。

## 3. O1--O6 小任务与 Git 边界

1. O0：冻结本文、边界数据 schema、周期 CGNS 约定和数值阈值。
2. O1a：读取/生成平移与旋转周期 CGNS，覆盖串行、叶块切分和 MPI 变换。
3. O1b：实现分边界数据、Couette/导热解析初场及严格配置测试。
4. O1c：建立发布网格生成器、配置模板、独立验证器和矩阵驱动器。
5. O2a：二维/三维自由流、两个 profile、单区运行时切分和原生多区等价性。
6. O2b：等熵涡光滑误差与交叉算法 smoke；Sod 和四象限间断健壮性。
7. O2c：Couette、线性导热、源项制造/解析响应和三维光滑问题。
8. O3：输出事件、所有格式、开关无扰动、同/异 rank 长段重启和周期/多块组合。
9. O4：配置、CGNS、分区、量、重启、非有限状态、输出和 MPI 错误路径。
10. O5：冻结数值/性能基线、许可证、支持环境、安装/运行说明和已知限制。
11. O6：从新构建目录执行全部发布矩阵，写报告，创建 `stage-o-release-candidate-v1` 并同步
    GitHub，然后停止在唯一的集中人工验收卡口。

每个小任务通过局部测试后独立提交并同步。普通开发失败不形成提交；若正式冻结矩阵失败，
必须提交失败报告或以可审计修复提交关闭，不能只修改输出数据。

## 4. 冻结数值矩阵

### 4.1 几何、自由流与分区

| 算例 | 快速矩阵 | 发布矩阵 | 通过条件 |
|---|---|---|---|
| 二维单区自由流 | 32×16，1/2 rank | 128×64，1/2/4/8 rank | 10 步后原始量最大误差 `<=1e-11`，全局守恒量相对漂移 `<=1e-12` |
| 二维原生多区 | 2 区各 16×16 | 2/4 区总计 128×64 | 与同网格运行时切分一步残差 `<=2e-11`，最终场 `<=2e-11` |
| 三维扭曲自由流 | 12×10×8，1/2 rank | 64×32×24，1/2/4/8 rank | 正 Jacobian，k 向实际切分，10 步误差 `<=2e-10` |
| 平移/旋转周期 | 16² / 小扇区 | 64² / 32×24×16 | 连接坐标 `<=1e-11`，Cartesian 状态/面量变换 `<=2e-10` |

上述自由流对 `phenglei_wcns` 和 `scmm6_wcns` 分别执行。负载目标为最大/平均单元数
`<=1.20`，每个不允许 idle 的 rank 必须拥有至少一个合法叶块。

### 4.2 光滑无粘

二维等熵涡采用 [`release-development-plan.md`](release-development-plan.md) 第 7.2 节解析式，
周期区域 `[0,10]^2`，终止时间 `t=10`。WENO-JS/WENO-Z/MDCD-LINEAR/MDCD-HYBRID 各在
32²、64²、128² 上与 HLLC 组合；两个 profile 至少覆盖 WENO-Z 和 MDCD-HYBRID。密度
`L1/L2/Linf` 均记录，64→128 的 `L1` 观测阶不得低于 3.5，128² 的 `L1<=2e-5`，守恒量
相对漂移 `<=2e-11`。4×3 重构/Riemann 全组合在 32² 推进 5 个 CFL 步，要求正性、有限性且
无未解释失败。1/2/4/8 rank 的最终场最大差 `<=2e-11`。

若边界/时间设置使某方法理论阶降低，必须先给出离散分析并单独修订本节，不能在看到结果后
直接降低阈值。

### 4.3 间断无粘

- Sod：快速 80×8、发布 400×40，`t=0.2`；WENO-Z/MDCD-HYBRID 特征重构分别配 HLLC、
  Roe，Rusanov 为基线。所有状态有限且 `rho,p` 严格大于 floor；一维精确解的截面密度
  `L1<=2.5e-2`，激波和接触位置误差各不超过 3 个 x 单元；1/2/4 rank 密度差 `<=2e-11`。
- Lax--Liu 配置 3：快速 64² 到 `t=0.05`，发布 200² 到 `t=0.3`；要求正性、有限性，关于
  对角交换后的对应积分差 `<=5e-4`，质量守恒误差按物理外流通量解释并记录。二维结构以
  冻结 CGNS 数据切片比较，不以肉眼图像作为唯一证据。

### 4.4 黏性、源项与定常停止

- Couette：周期 x、上下指定移动等温壁，快速 16×24、发布 32×64。用可配置解析初场检查
  一步动量平衡 `<=2e-10`；定常运行必须由残差连续判据结束，速度 `L2<=2e-4`，壁面剪切与
  `1/Re` 关系相对误差 `<=2%`。
- 线性导热：周期 x、上下 `T=1,2` 等温壁，`u=v=0`、常压、`rho=p/T`。一步质量/动量残差
  `<=2e-10`、温度 `L2<=2e-5`、上下热流不平衡相对值 `<=5e-4`，并正常定常收敛。
- 均匀守恒源：全周期均匀场，以常源推进到冻结时间；五个守恒量与解析线性响应最大差
  `<=2e-12`，1/2/4 rank 一致且准确命中 `t_end`。
- 制造源 smoke：二维/三维各运行至少 5 步，验证每个 RK 子步时间被使用、正性、源项积分
  和相同分区下串并行一致。完整空间/时间阶若当前源模型不足以构造闭式解，作为已知限制写入
  发布报告，不伪造阶数结论。

### 4.5 三维功能

除扭曲自由流外，使用 `manufactured_periodic` 的三维光滑场覆盖非零 w、三维度量、k 向分区、
CGNS/Tecplot 输出和异 rank 重启。快速 12³，发布 32³，运行 5 步；所有状态/Jacobian 有限
且正，1/2/4/8 rank 最终守恒场最大差 `<=5e-10`。涡量和 Q 尚未成为内建输出量时必须在
发布限制中明确，不能以二维零值代替。

## 5. 输出、重启、停止和失败矩阵

1. 非平凡场连续 100 步与 40+60 步续算比较；1→1 和 1→2/4 rank 的最终守恒场最大差
   `<=2e-11`，残差采样时刻和守恒统计一致。
2. 同时启用 `every_steps`、`every_time`、重合 `explicit_times` 和初末输出，文件集合与冻结
   事件表完全相同，无重复 `(kind,step,time)`。
3. 独立重读 CGNS/Tecplot 流场、TXT/Tecplot 历史/统计和检查点；自定义字段/统计量与离线
   重算差 `<=1e-12`。输出全关与全开最终守恒场差 `<=2e-12`。
4. 未知/重复配置、直接 Re/Ma、未知/循环量、不可行切分、非互逆连接、损坏 CGNS、重启
   签名不匹配、非有限状态和输出冲突均须按冻结退出码失败；MPI 不死锁，临时文件不被当成
   有效最终文件。

## 6. 发布记录与人工卡口

发布报告逐项记录配置摘要、网格尺寸/签名、提交、命令、rank、停止原因、误差/守恒/负载、
墙钟和峰值内存。性能只冻结可复现基线，不设置与机器偶然波动相关的速度硬阈值；但不得出现
空闲 rank、重复全 zone 坐标分配或除根 rank 输出重组外的非预期全局复制。

O6 只有在工作树干净、远程分支和所有候选标签同步、README/运行指南/算例说明/许可证与
已知限制完整后才形成候选。此后停止自动开发，等待项目负责人人工检查；未获批准不得合并
`main` 或创建正式版本标签。
