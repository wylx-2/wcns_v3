## 2. 清理内容

1. 增加 `.clang-format`、`.editorconfig`、`.gitattributes` 和 `pyproject.toml`，统一 C/C++、
   Python、UTF-8/LF 和基础缩进规则。
2. 机械格式化 157 个 tracked C/C++ 文件和 32 个 tracked Python 文件。C/C++ 格式前后
   词法记号完全一致（相邻字符串字面量按编译期拼接归一化）；Python 格式前后 AST 完全一致。
3. 删除 2 个未使用 Python 导入、2 个从未读取的 Case07 中间变量、4 个冗余 Riemann 成员
   值初始化和 1 个两分支恒等的条件表达式。
4. 三个 MPI 消息标签仅在 `WCNS_HAS_MPI` 时声明；配置默认字符串使用 `string_view` 避免未
   采用默认值时构造临时字符串；槽道壁面注册避免入口参数副本；旧 Euler 包装器将已取得所有权
   的参数移动到成员。以上均保持调用结果和外部接口语义。
5. 重复的发布矩阵脚本框架没有跨文件合并。它们需要保持可独立调用、可复制和历史命令兼容；
   公共化会扩大本次无功能清理的依赖与验收范围。MPI runtime 的 `owns_mpi_` 也保留，因为它在
   MPI 构建负责决定析构时是否调用 `MPI_Finalize`，只是串行静态分析不可见。
